## Nos

A **reciprocal** action is one that two or more people do to each other: "we hug each other", "they call each other". Spanish uses the plural reflexive pronouns for this: *nos, os, se*.

With a *nosotros* subject, the pronoun is *nos*:

» *Nos queremos mucho.* — We love each other very much.
» *Nos vemos mañana.* — See you tomorrow (literally: we see each other tomorrow).
» *Nos conocimos en la universidad.* — We met (each other) at university.
» *Nos escribimos cada semana.* — We write to each other every week.
» *Mi hermano y yo nos llamamos los domingos.* — My brother and I call each other on Sundays.

Because the action goes both ways, the verb must be plural and there must be at least two people.

### Placement

*Nos* behaves like any object pronoun: before conjugated verbs, attached to infinitives, gerunds and affirmative commands.

» *Vamos a ayudarnos.* = *Nos vamos a ayudar.* — We're going to help each other.
» *Estamos mirándonos.* — We're looking at each other.
» *¡Abracémonos!* — Let's hug!

> [!hack] Nos vemos
> *Nos vemos* is one of the most common ways to say goodbye. It's a reciprocal: we'll see each other.

## Os

With a *vosotros* subject (used in Spain), the reciprocal pronoun is *os*:

» *¿Os conocéis?* — Do you (two) know each other?
» *Os parecéis mucho.* — You look a lot like each other.
» *¿Cuándo os casasteis?* — When did you get married?
» *Os ayudáis siempre.* — You always help each other.
» *Os tenéis que perdonar.* = *Tenéis que perdonaros.* — You have to forgive each other.

With an affirmative *vosotros* command, the final *-d* drops before *os*: *ayudad + os → ayudaos* (help each other), *abrazad + os → abrazaos*. The exception is *idos* (go away).

In Latin America, where *vosotros* isn't used, the same idea uses *ustedes* and *se*: *¿Se conocen?*

> [!fact] Os is only Spain
> If you're learning Latin American Spanish, you only need to recognise *os*; you'll use *se* with *ustedes* instead.

## Se

With *ellos, ellas* or *ustedes*, the reciprocal pronoun is *se*:

» *Mis padres se quieren.* — My parents love each other.
» *Los jugadores se saludaron.* — The players greeted each other.
» *Ana y Luis se besan.* — Ana and Luis kiss.
» *¿Ustedes se hablan todavía?* — Do you still talk to each other?

### Reciprocal or reflexive?

*Se* (and *nos, os*) can be reflexive or reciprocal, so a sentence can be ambiguous:

» *Se miran.* — They look at themselves (in a mirror) / They look at each other.

To make the reciprocal meaning clear, add *el uno al otro* (or *la una a la otra*, *los unos a los otros*, *mutuamente*, *entre sí*):

» *Se miran el uno al otro.* — They look at each other.
» *Se ayudan mutuamente.* — They help each other.
» *Las hermanas se abrazaron la una a la otra.* — The sisters hugged each other.

To stress the reflexive meaning, use *a sí mismos*: *Se miran a sí mismos.* — They look at themselves.

> [!trap] Agreement of el uno al otro
> Use the masculine *el uno al otro* for two men or a mixed pair; *la una a la otra* for two women. The preposition matches the verb: *hablarse el uno con el otro*.

## Comprehensive Review 1

| Subject | Pronoun | Example |
|---|---|---|
| *nosotros/as* | *nos* | *Nos entendemos.* — We understand each other. |
| *vosotros/as* | *os* | *Os entendéis.* |
| *ellos / ellas / ustedes* | *se* | *Se entienden.* |

Common reciprocal verbs: *abrazarse* (to hug), *besarse* (to kiss), *conocerse* (to meet / know each other), *verse* (to see each other), *llamarse* (to call each other), *escribirse* (to write to each other), *ayudarse* (to help each other), *casarse* (to marry), *pelearse* (to fight), *enamorarse* (to fall in love), *saludarse* (to greet), *odiarse* (to hate each other), *entenderse* (to get on, understand each other), *despedirse* (to say goodbye).

Fill in:

» *Mi novio y yo ___ (conocerse) en 2019.* → *nos conocimos*
» *¿Vosotros ___ (escribirse) a menudo?* → *os escribís*
» *Los perros ___ (pelearse) todo el tiempo.* → *se pelean*

## Comprehensive Review 2

Reflexive, reciprocal or ambiguous?

» *Me peino.* → reflexive (only one person)
» *Nos abrazamos.* → reciprocal
» *Se lavan.* → ambiguous (themselves or each other)
» *Se ayudan el uno al otro.* → reciprocal (made clear)

Translate:

» We see each other every day. → *Nos vemos todos los días.*
» Do you (*ustedes*) know each other? → *¿Se conocen?*
» They said goodbye to each other at the station. → *Se despidieron en la estación.*
» The two women helped each other. → *Las dos mujeres se ayudaron la una a la otra.*

> [!hack] Singular means not reciprocal
> If the verb is singular, the meaning can't be "each other": *Ella se mira* can only mean "She looks at herself".
