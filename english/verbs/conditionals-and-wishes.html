Conditionals

Imagined situations

Conditional sentences talk about a situation (the condition, often with if) and its consequence (the main clause): If it rains, we'll stay at home.

Order of clauses

The if-clause can come first (followed by a comma) or second (no comma): If you're hungry, eat something. / Eat something if you're hungry.

Verb forms in the conditional clause

We don't normally use will in the if-clause, even about the future: If it will rain → If it rains. (Exception: will for willingness or polite requests: If you will wait here, I'll get him.)

Conditionals: if

Real conditionals (zero conditional)

For general truths and things that always happen: if + present, present: If you heat water to 100 °C, it boils. If I drink coffee late, I can't sleep.

First conditional

Possible future situations: if + present, will + base form: If it rains tomorrow, we'll stay at home. Other modals and imperatives are possible: If you see Tom, tell him to call me. If you finish early, you can go.

Second conditional

Imagined, unlikely or unreal present / future situations: if + past simple, would + base form: If I won the lottery, I would travel the world. If I had more time, I'd learn the piano. With be, were is used for all persons in formal English: If I were you, I'd accept. (also was in speech)

First and second compared

  • If I see him, I'll tell him. (I think it's possible)
  • If I saw him, I'd tell him. (I don't think I will)

Third conditional

Imagined past situations that didn't happen: if + past perfect, would have + past participle: If I had known, I would have helped. If she hadn't missed the bus, she wouldn't have been late.

Mixed conditionals

A past condition with a present result, or vice versa: If I had studied medicine, I'd be a doctor now. If I wasn't so shy, I would have spoken to her.

Conditionals: other expressions (unless, should, as long as)

  • unless = if not: I'll go unless it rains. (= if it doesn't rain) Not: unless it doesn't rain
  • should with inversion (formal, less likely): Should you need help, please call.
  • had with inversion (formal third conditional): Had I known, I would have come.
  • were with inversion: Were I in your position, I'd resign.
  • if … were to (hypothetical future): If it were to rain, the event would be cancelled.
  • as / so long as, provided (that), providing (that), on condition that = only if: You can borrow it as long as you return it.
  • or / otherwise: Hurry, or we'll miss the train. Wear a coat, otherwise you'll be cold.
  • supposing / suppose = imagine if: Supposing you lost your job, what would you do?

Conditionals: typical errors

  • will / would in the if-clause: If I will see her → If I see her; If I would have → If I had
  • wrong third conditional: If I would have known, I would come. → If I had known, I would have come.
  • unless + negative: unless you don't hurry → unless you hurry
  • If I was you is informal; in writing use If I were you

If only

If only expresses a strong wish or regret. It is stronger than I wish and uses the same verb forms:

  • present: If only I had more money! (I don't)
  • past: If only I hadn't said that! (I did)
  • future / annoyance: If only it would stop raining!

In case (of)

In case

In case means "as a precaution, because something might happen". It is followed by the present (for the future) or past: Take an umbrella in case it rains. I wrote it down in case I forgot. It is not the same as if: I'll buy food if guests come (only when they come) / I'll buy food in case guests come (before, just to be safe).

In case of

In case of + noun (formal, notices) means "if there is": In case of fire, break the glass.

Suppose, supposing and what if

Suggestions

Suppose / Supposing + present or past makes a suggestion: Suppose we meet at six? Supposing we took a taxi?

Imagining possibilities

They also ask about imagined situations, like what if: What if the plane is late? Supposing you won, what would you buy? Suppose he had refused — what then?

Wish

Wish + to-infinitive

Formal for want: I wish to speak to the manager.

Wish + objects

For greetings: We wish you a merry Christmas. I wished her good luck.

Wish + that-clause and verb forms

Wish about Form Example
present past simple / continuous I wish I had a car. I wish it wasn't / weren't raining.
past past perfect I wish I had studied harder.
ability could I wish I could swim.

Wish + would

Wish + would expresses annoyance about someone's behaviour or a wish for change: I wish you would stop talking. I wish it would stop raining. Not with I as the subject of both: I wish I would → I wish I could.
