Gotchas and false friends

Most learner mistakes at A2–B1 come from a short list of look-alike words, confusable pairs and literal translations from English or Ukrainian; this sheet lists them with the correct German.

False friends and traps for Ukrainian speakers

Many international words exist in both languages with a shifted meaning; trust the German meaning, not the Ukrainian echo.

German Real meaning Ukrainian look-alike in German Example

Confusing pairs

Each row splits one English or Ukrainian idea into several German words; pick by the rule in the middle column.

Words Which one when Ukrainian / English hint Example
kennen / wissen / können kennen = be familiar with a person, place, thing; wissen = know a fact (often + dass/ob/wer); können = know how to, be able знати (когось) / знати (що) / вміти Ich kenne Berlin. / Ich weiß, wo er wohnt. / Ich kann schwimmen. Ich kann Deutsch.
lernen / lehren / studieren lernen = learn, study for school; lehren = teach (formal, usually unterrichten); studieren = study at university вчити / викладати / навчатися в університеті Ich lerne für die Prüfung. / Sie unterrichtet Mathe. / Er studiert Informatik.
wer / wo / wohin / woher wer = who; wo = where (location); wohin = where to; woher = where from хто / де / куди / звідки; English "where" covers three Wo wohnst du? Wohin fährst du? Woher kommst du? Wer ist das?
seit / seid seit = since, for (time); seid = (ihr) are Ich wohne seit 2023 hier. / Seid ihr müde?
das / dass das = the, that (article, pronoun, relative); dass = conjunction "that" той / що Das Buch, das ich lese. / Ich denke, dass es regnet.
wenn / als / ob als = one past event; wenn = whenever (repeated) or if/when (now, future); ob = whether коли (одноразово) / коли, якщо / чи Als ich klein war, ... / Wenn es regnet, bleibe ich hier. / Ich weiß nicht, ob er kommt.
fragen / bitten / beten fragen = ask a question; bitten (um) = ask for, request; beten = pray питати / просити / молитися Ich frage ihn nach dem Weg. / Ich bitte dich um Hilfe.
leihen / borgen / ausleihen leihen and borgen = lend or borrow (jemandem etwas = lend; sich etwas = borrow); ausleihen = borrow, esp. from a library позичати / позичити Kannst du mir 10 Euro leihen? / Ich leihe mir ein Buch aus.
legen / liegen legen = put down flat (action, + Akk, regular: legte); liegen = lie, be lying (state, + Dat, lag, gelegen) класти / лежати Ich lege das Buch auf den Tisch. Das Buch liegt auf dem Tisch.
stellen / stehen stellen = put upright (action, Akk); stehen = stand (state, Dat) ставити / стояти Ich stelle die Flasche in den Kühlschrank. Sie steht im Kühlschrank.
setzen / sitzen sich setzen = sit down (action, Akk); sitzen = be sitting (state, Dat) сідати / сидіти Setz dich auf das Sofa! Ich sitze auf dem Sofa.
hängen (hängte) / hängen (hing) Same verb, action = hängte (Akk); state = hing (Dat) вішати / висіти Ich hängte das Bild an die Wand. Das Bild hing an der Wand.
mögen / möchten / gefallen / gern mögen = like in general (+ noun); möchten = would like (polite wish); gefallen = appeal to (Dat, looks, impressions); gern = like doing (with a verb) любити / хотіти б / подобатися / любити + inf Ich mag Kaffee. / Ich möchte einen Kaffee. / Die Jacke gefällt mir. / Ich trinke gern Kaffee.
sondern / aber sondern = "but rather" after a negative, replacing it; aber = but (contrast, both true) а / але (Ukrainian makes the same split) Nicht heute, sondern morgen. / Es ist teuer, aber gut.
schon / noch / erst schon = already; noch = still, yet; erst = only (so far, later than expected), not until вже / ще / лише (тільки що) Es ist schon 10 Uhr. / Er schläft noch. / Er kommt erst morgen. Ich bin erst 20.
nicht mehr / noch nicht nicht mehr = no longer; noch nicht = not yet. Answers: schon ↔ noch nicht; noch ↔ nicht mehr вже не / ще не Ich rauche nicht mehr. / Ich bin noch nicht fertig.
nur / erst nur = only (amount, final); erst = only so far, more may come тільки / лише ще Ich habe nur 5 Euro. / Ich habe erst drei Seiten gelesen.
Uhr / Stunde / Mal / Zeit die Uhr = clock, o'clock; die Stunde = hour, lesson; das Mal = time (occurrence); die Zeit = time (in general) годинник, о ... / година / раз / час Um 3 Uhr. / Zwei Stunden. / Das erste Mal. / Ich habe keine Zeit.
spät / später / zu spät spät = late; später = later; zu spät = too late (for something) Es ist spät. / Bis später! / Ich komme zu spät.
Wie spät ist es? What time is it? (= Wie viel Uhr ist es?), not "how late" Котра година?
sehr / viel sehr = very (+ adjective, + verb); viel = much, a lot (+ noun, + verb) дуже / багато sehr gut / Danke sehr! / viel Geld / Ich arbeite viel. / Ich mag dich sehr.
man / Mann man = one, people, you (pronoun, one n, lowercase); der Mann = man, husband неозначено-особове (кажуть, тут не палять) Hier darf man nicht rauchen. / Mein Mann kocht.
zu / nach / in nach = towns, countries without article, nach Hause; zu = people, shops, places, events; in = into a building or a country with article до / в Ich fahre nach Wien, zu meiner Tante, in die Schweiz, zum Arzt.
zu Hause / nach Hause zu Hause = at home (location); nach Hause = home (direction) вдома / додому Ich bin zu Hause. Ich gehe nach Hause.
ziemlich quite, rather (fairly strong, not "pretty" as in beautiful) досить Das ist ziemlich teuer.
eventuell / endlich / schließlich eventuell = maybe; endlich = finally (at last, relief); schließlich = in the end, after all можливо / нарешті / зрештою Endlich Wochenende! / Schließlich hat er Ja gesagt.
das Ende / zu Ende / am Ende das Ende = the end; zu Ende = finished, over; am Ende = at the end, in the end Der Film ist zu Ende. / Am Ende hat er gewonnen.
denken / glauben / meinen denken = think (about = an + Akk); glauben = believe, guess; meinen = have an opinion, mean Ich denke an dich. / Ich glaube, er kommt. / Was meinst du?
sagen / sprechen / reden / erzählen sagen = say (words, + Dat); sprechen = speak (language, to someone); reden = talk, chat; erzählen = tell (a story) казати / говорити / розмовляти / розповідати Er sagt nichts. / Ich spreche Deutsch. / Wir reden über Politik. / Erzähl mal!
gehen / fahren gehen = walk, go on foot (also general "go"); fahren = go by vehicle йти / їхати (same split as Ukrainian) Ich fahre mit dem Bus zur Arbeit.
bringen / nehmen / holen bringen = bring, take to; nehmen = take; holen = fetch, go and get приносити / брати / приносити (за чимось сходивши) Ich hole Brötchen.
warten / erwarten warten auf = wait for; erwarten = expect чекати на / очікувати Ich warte auf den Bus. / Ich erwarte ein Kind.

Spelling and pronunciation traps

German spelling is regular once you know about a dozen rules; most traps come from reading letters the English way.

Trap Rule Ukrainian / English hint Example
ei vs ie ei = "ai" [aɪ]; ie = long "i" [iː]. Say the second letter in English ei ≈ ай, ie ≈ іі mein, Wein, drei / Liebe, vier, Brief, sieben
eu / äu Both = "oi" [ɔʏ] ≈ ой neu, heute, Leute, Häuser
ß vs ss ß after a long vowel or diphthong; ss after a short vowel Straße, groß, weiß, Fuß / Wasser, Klasse, muss, dass
ß in Switzerland Swiss German writes ss everywhere Strasse
Capital nouns Every noun and nominalisation is capitalised das Haus, die Liebe, beim Essen, etwas Gutes
Sie vs sie Sie = formal you (always capitalised); sie = she, they; verb shows which Kommen Sie? (you) / Sie kommt. (she) / Sie kommen. (they or you)
du / dein in letters Lowercase is standard; capital Du allowed in letters and messages Wie geht es dir / Dir?
v = f v is usually [f] in German words; [v] in loanwords ф Vater, viel, vier / Vase, Video, Klavier
w = v w is always [v] в Wasser, wie, Wien
z = ts z (and tz) = [ts] ц Zeit, zehn, Katze, Pizza
s before a vowel s at the start of a syllable before a vowel = [z] (voiced) з Sonne, sie, Hose
st / sp at the start st- and sp- at the beginning of a word or stem = "scht", "schp" шт / шп Stadt, Straße, versteht, sprechen, Sport / but: Fenster, Wespe (middle)
sch [ʃ] like sh ш Schule, schnell
ch after a, o, u, au Throaty [x], like Ukrainian х х Bach, Buch, auch, noch
ch after e, i, ä, ö, ü, consonants, -chen Soft [ç], х said with the tongue high, "hissing" хь (м'яке) ich, nicht, Mädchen, München, durch, Märchen
-ig at the end Pronounced like -ich in standard German billig, zwanzig, König
j [j] like y in yes й ja, Jahr, jung
r Usually throaty [ʁ]; after a vowel at the end almost an "a" rot, Brot / Vater, hier, der
h after a vowel Silent; marks a long vowel gehen, Uhr, Sohn, fahren
Final devoicing b, d, g, s at the end of a syllable sound p, t, k, s Standard Ukrainian keeps voiced endings (дуб ends in a real б); German devoices them Hund [t], Tag [k], gelb [p], Kind [t], ab [p]
Long vowel signs Doubled vowel, vowel + h, or ie: long Meer, Boot, Zahn, Bier
Short vowel signs Vowel + double consonant or two consonants: short Bett, kommen, Mutter, Kind
Minimal pairs Length changes meaning Staat / Stadt, bieten / bitten, Miete / Mitte, Ofen / offen
Umlaut ä, ö, ü ä ≈ open e; ö = e with rounded lips; ü = i with rounded lips; never drop the dots ü ≈ ю without the й schön vs schon, würde vs wurde, Brüder vs Bruder
ae, oe, ue Replace ä, ö, ü when the keyboard has none Mueller = Müller
Glottal stop Words starting with a vowel get a tiny break, no linking am Abend (am + tiny break + Abend), not "a-ma-bend"

Gender traps

German grammatical gender often ignores real-world sex and rarely matches Ukrainian; learn every noun with its article (see Noun gender and plurals), and watch the words whose meaning changes with the article.

Noun Gender and meaning Why it trips you Example
das Mädchen neuter: girl -chen makes every noun neuter (дівчина is feminine) Das Mädchen spielt. (pronoun in speech: es or, increasingly, sie)
das Kind neuter: child дитина is feminine Das Kind schläft.
der See / die See der See = lake; die See = sea (= das Meer) Same word, two genders Wir baden im See. / Er fährt zur See.
das Band / der Band / die Band das Band = ribbon, tape, bond; der Band = volume (book); die Band = music band Three meanings der erste Band von Harry Potter / Die Band spielt live.
der Teil / das Teil der Teil = part, share; das Teil = a piece, a separate item (also colloquial "thing") Both mean part, nuance differs Der größte Teil der Arbeit. / Das Teil ist kaputt.
die Butter feminine: butter масло is neuter Die Butter ist im Kühlschrank.
das Gehalt / der Gehalt das Gehalt = salary; der Gehalt = content (Alkoholgehalt) Same word, two genders Mein Gehalt kommt am Ende des Monats.
die Steuer / das Steuer die Steuer = tax; das Steuer = steering wheel Wer sitzt am Steuer?
der Leiter / die Leiter der Leiter = head, manager; die Leiter = ladder
der Kunde / die Kunde der Kunde = customer; die Kunde = news (old-fashioned)
die Sonne / der Mond sun is feminine, moon masculine сонце n, місяць m; Sonne differs from Ukrainian; Mond happens to match (masculine)
das Problem, das Thema, das System, das Programm neuter Greek -a/-em words: feminine in Ukrainian (проблема, тема, система, програма) Kein Problem!

der Tee, der Kaffee masculine кава feminine
das Bier, das Wasser neuter вода feminine

Grammar traps

These are the literal translations from Ukrainian or English that Germans notice at once; the right column is what a native speaker says.

Trap Wrong (literal) Right German Why
Yes to a negative question Kommst du nicht? – Ja. Doch! (yes, I am) / Nein. (no, I'm not) Ja after a negative is confusing; Doch contradicts it
kein vs nicht Ich habe nicht Auto. Ich habe kein Auto. kein negates nouns with ein or no article; nicht negates verbs, adjectives, definite nouns: Ich habe das Auto nicht.
Double negation Ich habe nicht nichts gesagt. / Niemand nicht kommt. Ich habe nichts gesagt. / Niemand kommt. Ukrainian ніхто не / нічого не doubles; German uses one negative only
mögen without object Ich mag. / Magst du? Ich mag das. / Magst du es? / Ja, gern. mögen needs an object; for activities use gern: Ich schwimme gern
Being cold, hot, bored Ich bin kalt. / Ich bin heiß. / Ich bin langweilig. Mir ist kalt. / Mir ist heiß. / Mir ist langweilig. Ich bin kalt = I am cold-hearted; ich bin heiß = I'm sexually excited (slang); ich bin langweilig = I'm boring (like мені холодно)
Asking a name Was ist dein Name? Wie heißt du? / Wie heißen Sie? Was ist dein Name is understood but sounds translated
Age Ich habe 30 Jahre. Ich bin 30 (Jahre alt). sein, like English, not haben
Hunger, thirst, fear Ich bin hungrig. (OK but bookish) Ich habe Hunger / Durst / Angst. haben + noun is the everyday form
How are you Wie bist du? Wie geht es dir? / Wie geht's? Wie bist du? means "what are you like?"
Having something Bei mir ist ein Auto. Ich habe ein Auto. у мене є = haben
seit + tense Ich wohne hier seit zwei Jahre. / Ich habe hier seit 2 Jahren gewohnt. Ich wohne seit zwei Jahren hier. seit + present tense for something still true; seit takes dative
Verb second Heute ich gehe ins Kino. Heute gehe ich ins Kino. The conjugated verb is always in position 2 in statements
Verb at the end ..., weil ich habe keine Zeit. ..., weil ich keine Zeit habe. weil, dass, wenn, ob, als send the verb to the end (see Word order) (spoken weil + V2 is common but informal)
anrufen + case Ich rufe dir an. Ich rufe dich an. дзвонити тобі is dative; anrufen takes accusative
fragen + case Ich frage dir. Ich frage dich. Accusative, like питати тебе
helfen, danken, gratulieren Ich helfe dich. Ich helfe dir. / Ich danke dir. / Ich gratuliere dir. Dative verbs, like допомагати тобі
heiraten Ich heirate mit ihr. Ich heirate sie. / Ich bin mit ihr verheiratet. heiraten takes a direct object
Professions Ich bin ein Lehrer. Ich bin Lehrer. No article with jobs and nationalities (Ich bin Ukrainer)
Languages Ich spreche das Deutsch. / Ich spreche auf Deutsch. Ich spreche Deutsch. / Sag das auf Deutsch. auf Deutsch = in German (saying something); no article for speaking a language
I will Ich will morgen kommen. (= I want) Ich komme morgen. / Ich werde morgen kommen. will = want; future uses present tense + time word or werden
Present for future Ich werde morgen arbeiten gehen. (OK but heavy) Morgen gehe ich arbeiten. Germans mostly use present tense with a time word
Going home vs at home Ich bin nach Hause. / Ich gehe zu Hause. Ich bin zu Hause. / Ich gehe nach Hause. location vs direction
Two-way prepositions Ich gehe in der Stadt. (= I walk around inside town) Ich gehe in die Stadt. Wohin? = accusative; Wo? = dative (see Prepositions: in, an, auf, vor and the rest)
"It is" there is Hier ist viele Leute. Hier sind viele Leute. / Es gibt viele Leute hier. Es gibt + Akk = there is/are (in general)
"I'm finished" Not wrong, but ambiguous: Ich bin fertig. Ich bin fertig. (done) / Ich bin fix und fertig. (exhausted) Ich bin fertig alone can also mean worn out; context decides
"I'm right" Ich bin richtig. Ich habe recht. / Du hast recht. recht haben, like твоя правда = du hast recht
"I agree" Ich bin einverstanden mit dir. (OK) / Ich stimme. Ich stimme dir zu. / Einverstanden! / Da hast du recht. zustimmen + Dat
"It's my turn" Es ist meine Reihe. Ich bin dran. / Ich bin an der Reihe.
"I miss you" Ich fehle dich. Ich vermisse dich. / Du fehlst mir. fehlen reverses subject and object, like мені тебе бракує
"Make a photo" Ich mache ein Foto. Correct! Ich mache ein Foto. German is like Ukrainian (зробити фото), not English take
"Take a decision" Ich mache eine Entscheidung. Ich treffe eine Entscheidung. / Ich entscheide mich. Fixed verb + noun pair (Funktionsverbgefüge)
"I'm sorry" Ich bin sorry. / Es tut mich leid. Es tut mir leid. / Sorry! leid tun + Dat

B2 confusables

At B2 the traps get subtler: both words are real and close in meaning, but Germans hear the difference at once.

Words Which one when Ukrainian / English hint Example
scheinbar / anscheinend scheinbar = only seemingly, but in fact not; anscheinend = apparently, it looks like it is true удавано, на перший погляд / мабуть, схоже Er ist nur scheinbar ruhig, innerlich kocht er. / Er ist anscheinend krank, er ist nicht gekommen.

(not: Wohl.)

nicht müssen / nicht brauchen zu / nicht dürfen nicht müssen = no obligation; nicht brauchen + zu = the same, more idiomatic; nicht dürfen = must not не треба / не можна Du musst nicht kommen. = Du brauchst nicht zu kommen. / Du darfst nicht kommen. (forbidden)
brauchen + zu (positive) Only with nur or erst: you only need to досить лише Du brauchst nur anzurufen. / Perfect: Du hättest nicht zu kommen brauchen.
ändern / verändern / wechseln ändern = modify, adjust; verändern = change deeply (character, appearance, the world); wechseln = swap one thing for another змінювати / змінюватися докорінно / міняти Ich habe meine Meinung geändert. / Du hast dich verändert. / Ich wechsle den Job, Geld, das Thema.
"change" elsewhere change trains = umsteigen; change clothes = sich umziehen; move house = umziehen пересідати / переодягатися / переїжджати In Köln müssen Sie umsteigen. / Ich ziehe mich schnell um.
lehnen / ablehnen / leihen lehnen = lean; ablehnen = reject, decline; leihen = lend, borrow ставити, спирати / відхиляти / позичати Er lehnt sich an die Wand. / Sie hat das Angebot abgelehnt. / Leihst du mir dein Rad?
lassen / verlassen / weggehen lassen = leave something somewhere, let; verlassen = leave a place or person (+ Akk); weggehen = leave, go away (no object) залишати / покидати / йти Ich habe den Schirm im Zug liegen lassen. / Er hat das Büro um 5 verlassen. / Ich gehe jetzt weg.
bitten um / fragen nach / eine Frage stellen bitten um + Akk = ask for (a favour, a thing); fragen nach + Dat = ask about, ask after; a question is gestellt, not gemacht просити про / питати про Ich bitte Sie um Geduld. / Er fragt nach dem Preis. / Sie hat nach dir gefragt. / Darf ich eine Frage stellen?
der Gewinn / der Gewinner / verdienen der Gewinn = profit, prize, winnings; der Gewinner = winner; verdienen = earn, deserve (gewinnen = win only) прибуток, виграш / переможець / заробляти Die Firma macht Gewinn. / Wer ist der Gewinner? / Ich verdiene 3.000 Euro.
die Kritik / der Kritiker die Kritik = criticism, also a review (Filmkritik); der Kritiker = the critic (person) критика / критик; English critique = Kritik, critic = Kritiker Die Kritik war hart. / Er ist Filmkritiker. / Sie übt Kritik an der Regierung.
sensibel / sensitiv / empfindlich sensibel = sensitive (people, topics, data); sensitiv = highly perceptive, rare; empfindlich = touchy, delicate (skin, devices) чутливий / вразливий ein sensibles Thema, sensible Daten / empfindliche Haut / Sei nicht so empfindlich!
konsequent / folgerichtig / folglich konsequent = consistent, firm, rigorous; folgerichtig = logical, following logically; folglich = consequently послідовний / логічний / отже Eltern müssen konsequent sein. / Die Entscheidung war folgerichtig. / Er war krank, folglich fehlte er.
effektiv / effizient / wirksam effektiv = effective, it works (colloquially also "in real terms"); effizient = efficient, little waste; wirksam = effective (medicine, measures) ефективний covers both: split it Die Methode ist effektiv. / Er arbeitet effizient. / Das Mittel ist sehr wirksam.

die Konsequenz means both "consequence" and "consistency": Konsequenzen ziehen = take action, draw conclusions.

Verb + preposition traps

Many verbs take a fixed preposition with a fixed case, and it is rarely the one English or Ukrainian suggests; learn the verb, the preposition and the case as one unit. For hypotheticals with Konjunktiv II (Wenn ich Zeit hätte, würde ich ...) and the werden passive, see Tenses, moods and the passive.

Verb Wrong (literal) Right German Note
sich freuen auf + Akk / über + Akk Ich freue mich über den Urlaub nächste Woche. Ich freue mich auf den Urlaub. / Ich freue mich über das Geschenk. auf = looking forward (future); über = glad about (now, past)
Angst haben vor + Dat Ich habe Angst von Hunden. Ich habe Angst vor Hunden. боятися (від) does not transfer
warten auf + Akk Ich warte für dich. Ich warte auf dich. English "wait for" misleads
sich interessieren für + Akk / interessiert sein an + Dat Ich interessiere mich an Kunst. Ich interessiere mich für Kunst. / Ich bin an der Stelle interessiert. Two constructions, two prepositions
teilnehmen an + Dat Ich nehme in dem Kurs teil. Ich nehme an dem Kurs teil. брати участь у = an
abhängen von + Dat Das hängt auf das Wetter ab. Das hängt vom Wetter ab. English "depend on" misleads
denken an / halten von / nachdenken über Was denkst du von der Idee? Was hältst du von der Idee? / Ich denke an dich. / Ich denke über dein Angebot nach. halten von = have an opinion of
sich beschäftigen mit + Dat Ich beschäftige mich über das Thema. Ich beschäftige mich mit dem Thema. deal with, work on
sich beschweren bei + Dat über + Akk Ich beschwere mich zu dem Vermieter. Ich beschwere mich beim Vermieter über den Lärm. bei = the person, über = the problem
sich bewerben bei + Dat um + Akk Ich bewerbe mich für eine Stelle in Siemens. Ich bewerbe mich bei Siemens um eine Stelle. Also correct: sich auf eine Stelle bewerben (job ad)
sich kümmern um + Akk Wer kümmert sich über die Kinder? Wer kümmert sich um die Kinder? look after, take care of
sich verlassen auf + Akk Du kannst dich an mich verlassen. Du kannst dich auf mich verlassen. rely on
sich gewöhnen an + Akk Ich habe mich zu dem Wetter gewöhnt. Ich habe mich an das Wetter gewöhnt. get used to
bestehen aus + Dat / auf + Dat Das Team besteht von fünf Leuten. Das Team besteht aus fünf Leuten. / Er besteht auf einer Antwort. aus = consist of; auf = insist on

Questions and pointers: for things use wo(r)- and da(r)- (Worauf wartest du? – Darauf, dass er anruft.); for people use preposition + pronoun (Auf wen wartest du? – Auf ihn.), never Worauf for a person.

Comma rules

German commas follow grammar, not breathing: every subordinate clause is fenced off by commas, even short ones, so many more commas appear than in English. Ukrainian works much the same way (що, який, тому що always take a comma).

Rule Comma? Example
Before a subordinate clause (dass, weil, ob, wenn, als, obwohl, damit, während, question words) Always Ich glaube, dass er recht hat. / Ich weiß nicht, wann er kommt.
Subordinate clause first Always, then the verb Wenn es regnet, bleibe ich zu Hause.
Relative clause Always, on both sides Das Buch, das ich lese, ist spannend.
Infinitive group with um, ohne, statt / anstatt, außer, als Must Er kam, um zu helfen. / Sie ging, ohne sich zu verabschieden.
Infinitive group that depends on a noun Must Ich habe keine Lust, heute zu arbeiten. / Er hatte die Idee, ein Café zu eröffnen.
Infinitive group announced by es, daran, damit, darauf (a pointer word) Must Ich liebe es, im Regen spazieren zu gehen. / Er denkt daran, das Studium abzubrechen.
Other infinitive groups Optional (use one if it helps reading) Ich versuche(,) pünktlich zu sein. / Er hat versprochen(,) mir zu helfen.
Before aber, sondern, doch, jedoch (connecting) Always Es ist teuer, aber gut. / Nicht heute, sondern morgen.
Two main clauses with und / oder Optional, usually none Ich koche und du deckst den Tisch.
Lists Between items, not before the last und Äpfel, Birnen und Bananen
Comparison with als / wie Only if a full clause follows Er ist größer als ich. / Es war teurer, als ich dachte.
Ja, nein, bitte, address After ja / nein at the start; around a name Ja, das stimmt. / Anna, kommst du?
Email greeting Comma after it, next line starts lowercase (unless a noun) Sehr geehrte Frau Müller, / vielen Dank für Ihre Nachricht.

The most common learner error is the missing comma before dass or weil, and the second is a comma before a plain und.

Getrennt- und Zusammenschreibung (one word or two?)

The rule of thumb: write two words when each keeps its literal meaning, one word when together they mean something new. Duden allows both spellings in a few cases, marked below.

Pattern Separate Together Note
Verb + verb spazieren gehen, schwimmen gehen, laufen lassen kennenlernen (also kennen lernen); sitzenbleiben = repeat a school year (also sitzen bleiben) Literal meaning: always separate (Bleib sitzen!)
Noun + verb Auto fahren, Rad fahren, Ski fahren, Klavier spielen teilnehmen, stattfinden, leidtun, eislaufen Together when the noun has faded: Es tut mir leid (lowercase leid)
Adjective + verb, literal vs new meaning frei sprechen (speak without notes), schwer fallen (fall heavily), klein schreiben (write small) freisprechen (acquit), schwerfallen (be hard for someone), kleinschreiben (write lowercase), schwarzfahren, krankschreiben Es fällt mir schwer. / Er fährt schwarz.
sein da sein, zusammen sein, fertig sein, vorbei sein never joined Ich bin gleich da.
Adverbs and pronouns wie viel, zu viel, so viel, gar nicht, zu Ende irgendwann, irgendwo, irgendetwas, irgendjemand, stattdessen wieviel is wrong
Home zu Hause, nach Hause zuhause, nachhause (both allowed); the noun is das Zuhause Ich bin zu Hause. / Mein Zuhause ist hier.
zurzeit / zur Zeit zur Zeit Goethes (in Goethe's time) zurzeit (currently) Er ist zurzeit krank.
Nominalised verb groups – beim Autofahren, das Kennenlernen, zum Spazierengehen Turned into a noun: one word, capital letter

When unsure, check the Duden entry; where the table gives two spellings ("also", "both allowed"), either is accepted in exams.

Writing traps: das / dass, seit / seid and other sound-alikes

These pairs sound the same (or almost), so spellcheckers miss them and even native speakers mix them up; each has a quick test.

Pair Test Example
das / dass If you can replace it with dieses, welches or dies, write das; if not, it is the conjunction dass (comma before it) Ich hoffe, dass das Auto, das ich gekauft habe, läuft.
seit / seid seit = since, for (time), think Zeit (both end in t); seid = ihr form of sein, also the ihr imperative Ich wohne seit 2023 hier. / Seid ihr fertig? / Seid leise!
wieder / wider wieder = again (wiederholen, Wiedersehen); wider = against (widersprechen, der Widerstand, erwidern = reply) Auf Wiedersehen! / Ich muss dir widersprechen.
der Tod / tot Tod = noun (death) and the prefix tod- = "extremely" (todmüde, todsicher); tot = adjective (dead) and verbs with tot- (totschlagen, sich totlachen) Er ist tot. / Ich bin todmüde. / Wir haben uns totgelacht.
end- / ent- end- comes from Ende (endlich, endgültig, das Endspiel); ent- is a prefix (entscheiden, entlassen, entwickeln) Endlich habe ich mich entschieden.
den / denn, wen / wenn den, wen = articles and pronouns (accusative); denn, wenn = conjunctions and particles Wen hast du gesehen? / Wenn du willst, komm mit.
Stadt / statt / Staat Stadt = city (short a); statt = instead of; Staat = state (long a) Statt in der Stadt wohnt er auf dem Land.
malen / mahlen, das Mal / das Mahl malen = paint, das Mal = time (occurrence); mahlen = grind, das Mahl = meal (formal) Ich male ein Bild. / Kaffee mahlen / zum ersten Mal
viel / fiel viel = much; fiel = past of fallen Es fiel viel Schnee.
die Lehre / die Leere Lehre = apprenticeship, lesson (from lehren); Leere = emptiness (from leer) Er macht eine Lehre als Koch.

Read your text once only for das/dass: it is the error teachers and HR departments notice first.
