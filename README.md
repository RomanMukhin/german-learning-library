# German library

A static website with reference docs, 40 B1 reading texts and quizzes for learning German (A2–B1+), explained in English with Ukrainian comparisons.

Plain HTML, no build step: open `index.html`, or host the folder as-is (Cloudflare Pages: framework preset "None", build command empty, output directory `/`).

The pages are generated. Edit the sources and rebuild instead of editing the HTML by hand.
